# CI/CD Practice

A software-engineering practice project focused on automated testing, containerization, and continuous integration/deployment concepts.

## What it demonstrates

- Python application packaging
- Automated test execution
- Docker-based application delivery
- GitHub Actions workflow configuration
- Tekton pipeline configuration
- Deployment-oriented project structure

## Repository structure

~~~text
ci-cd-final-project-main/
├── service/       # Application/service code
├── tests/         # Automated tests
├── .github/       # GitHub workflow configuration
├── tekton/        # Tekton pipeline definitions
├── Dockerfile
├── requirements.txt
└── setup.cfg
~~~

## Engineering focus

This repository is primarily a DevOps learning project. The emphasis is on repeatable builds, test automation, and pipeline concepts rather than product functionality.

## Getting started

See the README inside ci-cd-final-project-main for the original project-specific execution instructions.

## Portfolio context

This is a supporting portfolio project demonstrating CI/CD and delivery practices alongside the larger application projects.
